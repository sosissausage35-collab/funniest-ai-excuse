Entry for the [make.fun bounty "The Funniest AI Excuse"](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0): a program that writes the funniest one-line excuse an AI agent gives after failing a task — at most 200 characters — to `/output/entry.txt`.

## The excuse

> The task is 90% done. The remaining 10% unionized and is demanding weekends off.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node.js 22+. The program is deterministic: it always writes the same line.
